# 回声 ECHO

> 黑暗中，想看见世界，就必须暴露自己。

一款**声呐潜行游戏**：你身处全黑的废弃设施，发射声呐脉冲后波纹扩散，撞到的墙壁轮廓被短暂点亮——但敌人也靠声音找你。每一次"看"世界，都是在暴露自己。

**在线试玩**：（发布后把 itch.io / GitHub Pages 链接贴在这里）

## 怎么玩

| 操作 | 按键 |
|---|---|
| 移动 | WASD / 方向键 |
| 发射声呐脉冲 | 点击 / 空格 |
| 静音 | M |
| 重试 | 点击 / R |

**规则**：从黑暗中找到出口即可过关，共三层。敌人看不见，只能被你的声音吸引——脉冲会暴露你的位置（第三层连脚步都会）。被抓即重来。

**提示**：戴耳机。回波的左右声道就是墙壁的方位。

## 设计支柱

1. **感知有代价**——获取信息这个动作本身就是风险
2. **单一决策的深度**——"现在要不要发声"一个决策贯穿全局
3. **世界只存在于回波中**——恐怖感来自空白，而不是怪物

完整设计文档（体验曲线、信号处理背景到玩法的转化、开发里程碑复盘、刻意不做清单）见 [DESIGN.md](DESIGN.md)。

## 技术

单 HTML 文件，零依赖，零素材：

- **渲染**：Canvas 2D——波纹扩散、墙壁揭示渐隐、发光叠加（`lighter`）、距离衰减配色
- **音效**：Web Audio 实时合成——回波在波前撞墙时刻触发，声像=方位角、响度=传播衰减能量；心跳间隔随敌人距离缩短。无任何音频文件
- **AI**：三态状态机（巡逻 → 循声 → 搜索）+ 卡墙检测
